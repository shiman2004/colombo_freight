# AeroVia Freight Landing Page

Premium responsive freight & logistics landing page built with React 18, TypeScript, Vite, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Images are loaded from Unsplash URLs. Replace the placeholder AeroVia brand name, company details, contact information, trade-lane data and testimonials with real business content before production.
